# Проект "Разработка веб-приложений на Django"

## Описание:
Данный проект - это комплекс домашних заданий по теме "Разработка веб-приложений на Django"

## Установка:
### 1. Клонируйте репозиторий: 

        https://github.com/basinanatali-star/Web_applications_on_Django.git

### 2. Установите зависимости:

        pip install -r requirements.txt

## Использование:
Это учебный проект, поэтому можно использовать его как образец.  

### Модули проекта:
* Модуль, содержащий виртуальное окружение.
* Модуль, содержащий конфигурацию проекта на Django
* Модуль, содержащий библиотеку элементов Bootstrap
* Модуль, содержащий приложение catalog
